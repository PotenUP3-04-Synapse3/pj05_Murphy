# 프로토타입 시나리오 상세안

## 시나리오명

**Chapter 0. Immigration Check**

## 부제

**첫 관문부터 석 out**

## 프로토타입 목표

사용자는 미국 공항 입국심사대에서 영어로 질문에 답해야 합니다.

AI Agent는 사용자의 발화를 분석하여 다음 요소를 판정합니다.

- 질문 의도 이해 여부
- 핵심 정보 전달 여부
- 영어 표현 수준
- 콩글리쉬 허용 가능성
- NPC 인내심 변화
- 다음 질문 / 재질문 / 힌트 / 통과 / 실패 엔딩 분기

---

# 1. 주요 등장 요소

## 플레이어

| 항목 | 내용 |
| --- | --- |
| 역할 | 미국에 입국하려는 한국인 여행자 |
| 상태 | 긴장했지만 입국심사를 통과해야 함 |
| 입력 방식 | Space Bar를 누르고 말하기 |
| 허용 발화 | 영어, 콩글리쉬, 한국어 섞인 답변 |
| 목표 | 입국심사 질문에 답하고 공항 밖으로 나가기 |

---

## NPC: Officer Miller

| 항목 | 내용 |
| --- | --- |
| 역할 | 미국 입국심사관 |
| 말투 | 짧고 공식적 |
| 성격 | 무뚝뚝하지만 불친절하지는 않음 |
| 목표 | 방문 목적, 체류 기간, 숙소, 귀국 계획 확인 |
| 상태 변수 | 인내심 / 의심도 / 티어별 태도 |

---

## 상태 변수

| 변수 | 설명 |
| --- | --- |
| `tier` | Bronze / Silver / Gold |
| `current_node` | 현재 질문 노드 |
| `patience` | NPC 인내심, 기본 100 |
| `suspicion` | 의심도, 기본 0 |
| `fail_count` | 실패 또는 불명확 답변 횟수 |
| `hint_used` | 힌트 사용 여부 |
| `slots` | 방문 목적, 체류 기간, 숙소, 귀국 항공권 등 |
| `ending_type` | Pass / Partial Pass / Secondary Room / 석 out |
