# Prototype Plan

# 프로토타입 발표 목표

## 6월 8일 발표에서 보여줘야 할 최종 데모

```
[메인 화면]
↓
[티어 선택: Bronze / Silver / Gold]
↓
[공항 입국심사장 진입]
↓
[플레이어가 심사대 앞으로 이동]
↓
[입국심사관 질문]
↓
[사용자 답변 입력: Space Bar / 텍스트 / STT 중 가능한 방식]
↓
[AI Agent가 답변 판정]
↓
[다음 질문 또는 재질문]
↓
[통과 / 부분 통과 / 코믹 실패 엔딩]
↓
[결과 리포트 출력]
```

프로토타입에서 반드시 보여야 할 핵심은 **영어 대화 자체**가 아니라, 사용자의 자유 발화를 Agent가 분석해 **시나리오 진행, NPC 반응, 결과 판정**으로 연결하는 구조입니다. 프로젝트 컨텍스트에서도 Agent는 단순 NPC 대화 생성기가 아니라, 사용자 발화와 문제 해결 상태를 분석해 시나리오를 운영하는 역할로 정의되어 있습니다.

---

# 일정 운영 원칙

## 1. 6월 5일까지 기능 구현 완료

6월 6일부터는 새 기능을 넣지 말고 **버그 수정, 발표 시연 안정화, 발표 자료 정리**에 집중해야 합니다.

## 2. STT/TTS는 필수가 아니라 옵션

발표일까지 시간이 짧으므로 우선순위는 다음과 같습니다.

1. **텍스트 입력 기반 Agent 판정**
2. Space Bar 기반 입력 UI
3. STT 연동
4. TTS 연동

음성 입력이 불안정하면 발표 때는 텍스트 입력 또는 더미 STT로도 충분합니다. 중요한 것은 **Unreal → AI 서버 → Agent 판정 → Unreal 결과 반영** 흐름입니다.

## 3. 멀티플레이, 수하물 분실, 호텔 이동은 제외

이번 프로토타입에서는 제외하는 것이 안전합니다.

회의록에서도 프로토타입은 티어 선택, 입국심사장, 줄 서기, 심사관 대화, 결과 출력 중심으로 정리되어 있습니다.
