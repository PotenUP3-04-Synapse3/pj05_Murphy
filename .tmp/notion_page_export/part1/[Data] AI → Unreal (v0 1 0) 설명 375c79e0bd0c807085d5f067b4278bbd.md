# **2. AI Backend → Unreal**

AI Backend는 최종 검증된 Unreal-safe JSON만 반환한다.

## **2.1 Response Root Fields**

| **Field** | **Example** | **필요성** |
| --- | --- | --- |
| contract_version | dev_c_unreal_response.v1 | 응답 schema 버전 |
| request_id | req_imm_0001 | 요청-응답 매칭 |
| session_id | session_001 | 세션 매칭 |
| turn_index | 2 | 턴 매칭 |
| current_node_id | IMM_002_PURPOSE | 처리된 현재 노드 |
| next_node_id | IMM_003_DURATION | Unreal이 이동할 다음 노드 |
| next_action | ADVANCE | Unreal이 실행할 대화/게임 action |
| stt | {...} | STT 결과와 디버그 정보 |
| npc | {...} | NPC 대사, tone, animation, audio |
| ui | {...} | 힌트/피드백 UI 표시 정보 |
| state_delta | {...} | Unreal state에 적용할 변화량 |
| evaluation | {...} | 플레이어 답변 평가 |
| report | {...} | 추후 final report용 기록 |
| debug | {...} | 개발/디버깅 정보. production에서는 생략 가능 |

## **2.2 next_action Values**

| **Value** | **의미** |
| --- | --- |
| ADVANCE | 다음 노드로 진행 |
| REASK | 같은/재시도 노드에서 다시 질문 |
| GIVE_HINT | 힌트 제공 |
| WARNING | 경고/위험 상황 |
| FAIL_END | bad ending |
| FINAL_DECISION | 최종 판정 |

## **2.3 stt**

| **Field** | **Example** | **필요성** |
| --- | --- | --- |
| model | whisper-large-v3-turbo | 사용한 STT 모델명 |
| primary_runtime | local | 기본 STT runtime |
| fallback_runtime | api | fallback runtime |
| runtime_used | local | 실제로 transcript를 만든 runtime |
| player_text | I'm here for tourism. | AI가 이해/평가에 사용한 최종 transcript |
| confidence | 0.87 or null | STT 신뢰도 |
| language_detected | en-US | 감지/힌트 언어 |
| needs_repeat | false | 다시 말하게 해야 하는지 |

## **2.4 npc**

| **Field** | **Example** | **필요성** |
| --- | --- | --- |
| speaker | Officer Miller | 말하는 NPC |
| text | You're here for tourism. How long will you stay? | 화면 subtitle/dialogue |
| tone | formal_neutral | 음성/애니메이션 tone |
| animation | officer_check_passport | Unreal animation hint |
| audio_url | /runtime/audio/kokoro/file.wav | NPC 음성 wav 접근 경로 |

## **2.5 ui**

| **Field** | **Example** | **필요성** |
| --- | --- | --- |
| show_hint | false | 힌트 UI 표시 여부 |
| hint_kr | null | 한국어 힌트 문구 |
| recommended_expression | I'm here for tourism. | 추천 영어 표현 |
| in_game_feedback.show | true | 피드백 UI 표시 여부 |
| in_game_feedback.feedback_strategy | recast | 피드백 방식 |
| in_game_feedback.priority | low | UI 우선순위 |

# **3. Unreal에서 우선 처리해야 하는 핵심 필드**

## **반드시 사용**

| **Field** | **사용처** |
| --- | --- |
| next_node_id | 다음 대화/시나리오 노드 이동 |
| next_action | 진행, 재질문, 힌트, 경고, 실패 처리 |
| npc.text | subtitle/dialogue 출력 |
| npc.audio_url | NPC 음성 재생 |
| npc.animation | NPC animation trigger |
| ui.show_hint | 힌트 UI 표시 |
| ui.hint_kr | 한국어 힌트 |
| ui.recommended_expression | 추천 표현 표시 |
| state_delta | Unreal game state 업데이트 |
| stt.player_text | 디버그/자막/테스트 확인 |

## **개발 중에만 사용 가능**

| **Field** | **사용처** |
| --- | --- |
| debug | AI flow 디버깅 |
| stt.runtime_used | local/API STT 확인 |
| evaluation.scores | 학습 UI/리포트 |
| report | 최종 피드백/학습 리포트 |
