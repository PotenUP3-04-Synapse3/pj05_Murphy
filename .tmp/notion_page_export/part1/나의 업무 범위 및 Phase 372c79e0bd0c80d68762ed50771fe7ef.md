# 나의 업무 범위 및 Phase

2026년 6월 1일 

# 나의 역할 한 줄 정의

> **플레이어의 입력을 받아 AI가 이해 가능한 구조로 만들고, OpenKB 기반 컨텍스트를 붙여 Understanding Agent를 실행한 뒤, 전체 AI 백엔드 응답을 안전한 JSON으로 조립하는 담당자**
> 

AI 백엔드의 입구 + 중앙 허브 + 검증 담당

# 담당 범위

```
1. STT Pipeline
2. AI Backend Orchestrator
3. OpenKB Retrieval
4. Understanding Agent
5. Validator
6. Unreal Response JSON Assembler
7. 로그 / 테스트 케이스 관리
```

```
Unreal Client
↓
[승헌] STT Pipeline
↓
[승헌] Orchestrator
↓
[승헌] OpenKB Retrieval
↓
[승헌] Understanding Agent
↓
[개발자 B] English Level & Hint Agent
↓
[개발자 B] Scenario State Machine
↓
[개발자 A] NPC Dialogue Agent
↓
[개발자 A] TTS
↓
[승헌] Validator
↓
[승헌] Final Response JSON
↓
Unreal Client
```

# 업무 단계:

## Phase 1. API 뼈대 만들기

| 작업 | 산출물 |
| --- | --- |
| `/api/game/ai/respond` 구현 | FastAPI 또는 백엔드 endpoint |
| Request schema 정의 | Pydantic / JSON Schema |
| Response schema 정의 | Unreal 응답 JSON |
| text input 우선 처리 | STT 없이도 테스트 가능 |
| 더미 응답 반환 | Unreal 연동 테스트용 |

---

## Phase 2. STT 붙이기

| 작업 | 산출물 |
| --- | --- |
| 음성 입력 포맷 확정 | Unreal ↔ Backend 음성 전송 방식 |
| STT 모듈 구현 | `voice → text` |
| STT confidence 반환 | `stt_confidence` |
| STT 실패 fallback | “Could you say that again?” |
| text/voice 공통 입력 구조화 | `normalized_player_input` |

---

## Phase 3. OpenKB 연동

| 작업 | 산출물 |
| --- | --- |
| node schema 확정 | 개발자 B와 협의 |
| current_node_id 기반 조회 | `get_node_context()` |
| node_context 생성 | Understanding Agent 입력용 |
| missing node fallback | 기본 재질문 노드 |
| allowed_next_nodes 관리 | Validator와 연결 |

---

## Phase 4. Understanding Agent 구현

| 작업 | 산출물 |
| --- | --- |
| Agent prompt 작성 | 의도/슬롯/위험도 분석 프롬프트 |
| 출력 JSON schema 고정 | `UnderstandingResult` |
| 노드별 intent 테스트 | passport, purpose, duration, stay, return |
| 콩글리쉬 테스트 | `Travel이요`, `Five days요` 등 |
| 위험 답변 테스트 | `forever`, `illegal`, `secret` 등 |

---

## Phase 5. Orchestration 연결

| 작업 | 산출물 |
| --- | --- |
| Understanding 결과를 B에게 전달 | Level & Hint 입력 |
| B의 State Machine 결과 수신 | branch result |
| A의 NPC Dialogue 결과 수신 | npc response |
| 최종 commands 조립 | Unreal 실행 명령 |
| 모듈 실패 시 fallback | 안정성 확보 |

---

## Phase 6. Validator 구현

| 작업 | 산출물 |
| --- | --- |
| allowed node 검증 | 없는 노드 차단 |
| command type 검증 | 허용 command만 실행 |
| animation id 검증 | 없는 애니메이션 차단 |
| response schema 검증 | Unreal 파싱 실패 방지 |
| fallback response 생성 | 오류 시 안전 응답 |

---

## Phase 7. 테스트 / 로그

| 작업 | 산출물 |
| --- | --- |
| 테스트 발화셋 작성 | 정상/애매/위험/콩글리쉬 |
| 요청/응답 로그 저장 | 디버깅 |
| Agent 결과 로그 저장 | intent, risk, slots |
| 실패 케이스 리포트 | STT 오인식, 잘못된 intent |
| 데모 시나리오 검증 | Happy / Retry / Bad Ending |
