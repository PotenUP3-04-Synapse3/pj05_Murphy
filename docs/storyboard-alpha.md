**슬라이드 19**  
제목: 시나리오 결과 분석: 피드백  
내용:  
Scoring Rubric  
• 점수 계산  
사용자의 모든 발화를 Agent가 기준에 따라 점수 판정, feedback 작성  
• 점수 저장 및 계산  
판정된 결과는 openKB로 저장되며, 시나리오 종료 후 항목별 평균/전체 평균 점수 제공  
• 피드백 제공  
암묵적(in-game) 피드백: NPC가 여러 가지 기법을 통해 feedback 제공  
명시적(out-game) 피드백: 의사소통에 장애가 있는 critical breakdown 순서로 제공되나, 티어별 피드백 제공  
브론즈  
의사소통에 문제가 있었던 부분(fluency) 중심으로, 에러 → 좋은 예시 제공  
실버  
의사소통적 요소와 문법적(accuracy) 설명 함께 제공  
골드  
제공할 피드백이 minor 할 경우, 간단한 팁(문화적 맥락적 요소) 제공
