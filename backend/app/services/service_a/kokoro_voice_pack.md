## 핵심 요약

- **여성 음성 (af\_)**: `af_heart`(기본값)를 중심으로 중성적/정보 전달형, 차분한 내레이션형, 밝고 가벼운 대화형으로 구분.
- **남성 음성 (am\_)**: 깊고 묵직한 저음형, 부드럽고 친숙한 톤, 신뢰감 있는 표준 내레이션형으로 구분.

---

## 1. 영어 — 미국식 여성 음성 (af\_\*) 특징

| 모델명                | 주요 특징                                         | 적합한 용도                         |
| :-------------------- | :------------------------------------------------ | :---------------------------------- |
| **af_heart (기본값)** | 가장 자연스럽고 따뜻한 감성을 지닌 표준 여성 음성 | 다목적 베이스, 일상 대화            |
| **af_alloy**          | 중성적이고 균형 잡힌 톤, 감정의 치우침이 적음     | 객관적인 정보 전달, 기술 문서       |
| **af_aoede**          | 차분하고 부드러운 목소리                          | 오디오북, 팟캐스트, 긴 글 읽기      |
| **af_bella**          | 안정감 있고 약간 무게감 있는 톤                   | 다큐멘터리, 진지한 내레이션         |
| **af_jessica**        | 또렷하고 명료한 발음                              | 교육용 자료, 프레젠테이션, 튜토리얼 |
| **af_kore**           | 뚜렷한 개성을 지닌 목소리                         | 캐릭터 기반 대화형 AI, 숏폼 콘텐츠  |
| **af_nicole**         | 전문적이고 신뢰감을 주는 아나운서 스타일          | 뉴스 리딩, ARS 안내 멘트            |
| **af_nova**           | 밝고 에너지가 느껴지는 톤                         | 광고, 프로모션 영상, 활기찬 안내    |
| **af_river**          | 잔잔하고 평온한 느낌                              | 명상 앱, 조용한 배경의 스토리텔링   |
| **af_sarah**          | 친숙하고 대화하는 듯한 자연스러운 톤              | 일상적인 대화 생성, 블로그 리딩     |
| **af_sky**            | 비교적 톤이 높고 가벼우며 산뜻한 목소리           | 경쾌한 분위기, 젊은 층 타겟 콘텐츠  |

## 2. 영어 — 미국식 남성 음성 (am\_\*) 특징

| 모델명         | 주요 특징                                | 적합한 용도                             |
| :------------- | :--------------------------------------- | :-------------------------------------- |
| **am_adam**    | 깊이 있고 명확한 중저음                  | 신뢰감을 주는 내레이션, 기업용 영상     |
| **am_echo**    | 부드럽고 울림이 있는 톤                  | 편안한 대화, 라디오 진행, 오디오북      |
| **am_eric**    | 친숙하고 캐주얼한 목소리                 | 일상적인 대화, 브이로그(Vlog) 더빙      |
| **am_fenrir**  | 다소 거칠고 무게감 있는 톤               | 극적인 연출, 오디오 드라마, 게임 캐릭터 |
| **am_liam**    | 젊고 활기찬 톤                           | 트렌디한 콘텐츠, 유튜브 리뷰 영상       |
| **am_michael** | 표준적이고 전문적인 남성 음성            | 정보 전달, 공식적인 안내 방송           |
| **am_onyx**    | 매우 낮고 묵직한 베이스 톤               | 강렬한 인상(영화 예고편), 진지한 다큐   |
| **am_puck**    | 개성 있고 비교적 높은 톤의 가벼운 목소리 | 애니메이션 캐릭터, 쾌활한 설명          |
| **am_santa**   | 따뜻하고 연륜이 묻어나는 풍부한 목소리   | 동화책 읽어주기, 감성적인 스토리텔링    |
